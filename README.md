# Steam Game Recommender

This is a project intended to practice the following concepts:
 - Domain Driven Design (DDD)
 - Writing REST-ful APIs
 - Using external APIs
 - Writing useful and pretty frontend
 - Database design
 - ORM tools
 - Recommendation algorithms
   - Computing vectors
